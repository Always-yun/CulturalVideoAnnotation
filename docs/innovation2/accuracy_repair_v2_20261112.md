# 准确率修复与论文评估记录（2026-11-12）

目标：提升文化符号的严格ID准确率，同时控制未知实体错误接受；不以全拒识换取低幻觉率，不修改GT迎合模型。

## 已确认问题

既有A/B/C开发对照仅落盘58/90，A/B各20条、C18条。B原始标注严格评分正确11/20，最终正确5/20；C原始标注正确11/18，最终正确5/18。原始标注分数不是关闭门控的独立实验：生成时已受门控提示影响，仅用于定位后处理损失。

B最终错误分解：8条Known检索Top-5缺失、5条身份核验拒绝、2条检索门控拒绝。C对应7、4、2。分解按最早可归因阶段记一次，不代表样本不存在其他问题。

- 结构化证据的background未传递到检索与身份核验。
- 结构化描述避免专名，但旧门控依赖KB词表命中，存在输入分布变化。
- 身份核验在选择待核验实体前截断前三个候选，可能核验错第4/5名的最终选择。
- 核验提示对区域/复合场所使用单体式exact identity，未充分使用KB范围。例：KB已有“城市广场与城楼”“城楼仰视”，不应额外要求整片广场同时入镜。该例只用于发现一般口径问题，代码无样本名特例。

## 本轮修改

1. 可选context_v2：主体与可读文字保持原有来源约束，追加明确标记的背景辅助证据；猜测不进入证据。背景不进入规则强身份通道，新排序的名称优先也不使用背景名称。
2. 可选kb_scope_v3：核验基于KB规范名、别名、类型、典型场景界定范围，再检查关键帧证据；同景区关系及范围外具名实体仍拒绝。不修改KB或GT，不放宽分数阈值。
3. 在全部检索候选中定位实际输出实体后再截断核验预算；找不到输出实体时拒绝，不默认为Top-1。

前两项仅由新实验入口启用，默认策略保留。原结果目录不覆盖，修改前源码存于outputs/accuracy_repair_v2/source_before。


27项回归测试通过，包括缓存证据不重调Pass-1、背景不能直接成为主体身份证据、核验第5名实际选择、候选外输出不得误接收Top-1。

新实验使用旧B组已完成的20条证据，B2/C2共40项；B2旧排序，C2证据排序。复用相同Pass-1和文字复核，仅重跑检索、最终标注及必要身份核验。C旧版只有18条，必须在同视频交集上比较；自动汇总paired提供配对计数，不用不同样本分母直接声称增益。运行日志为/tmp/accuracy_repair_v2_run.log。代码、配置、GT、来源证据哈希写入新manifest；变化后拒绝混跑。

## 论文口径

- 这20条属于开发集，不能作为独立测试收益；正式结果需冻结方案后用未参与开发的验证/测试素材。
- 主指标：全体严格ID准确率、Known准确率、Known误拒率、Unknown错误接受率；诊断指标：Recall@1/@5、门控各阶段损失、按视频API调用与耗时。
- 当前Unknown只有2条，无法证明开放集泛化；应补充具有视觉近邻的Hard Unknown及Easy Unknown。
- 正式划分应按实体/拍摄来源分组，避免同一视频裁剪或同实体近重复跨验证/测试。
- 本轮组合修复衡量总体工程效果，不声称每个改动单独贡献。若整体有效，再做背景证据、范围核验的逐项消融。
- 若新方案仍不及A，应如实保留负结果。下一轮优先评估“身份假设用于召回、真实证据用于核验”的分离设计，而非继续全局降低拒识阈值。

## 结果

40/40已完成，共51次成功运行中的API调用。B2为20条中5条正确，Known 3/18=16.67%；C2为20条中6条正确，Known 4/18=22.22%。两组各2条Unknown均拒识。

严格配对：B旧/新均5/20正确；C共同18条旧/新均5/18正确，无修复也无退步。C2增加的1条正确来自旧C尚未运行的样本，不能算改进。结论：本轮工程修复没有观察到最终准确率收益，不能据此宣称方法有效。

## 离线联合召回探测

对相同18个Known视频重新计算全库CLIP图像分数，各文本方案共享分数，不调用GLM。旧描述Recall@5=14/18=77.78%；结构化描述=10/18=55.56%；补背景仍为10/18；旧描述与结构化证据联合=16/18=88.89%，Recall@1=12/18=66.67%。

这只是候选召回诊断，不是最终准确率。联合方案还使用了旧A描述，实际系统须计入额外证据提取成本，不能视为免费提升。详见outputs/accuracy_repair_v2/recall_probe.json。

## 下一轮执行顺序

1. 修复格式错误恢复：有限重试，无法解析则记运行失败，避免伪装成“无文化符号”。
2. 将身份假设与观察证据分字段保存：旧式命名线索仅用于召回，不作为强身份证据；联合结构化证据召回候选。
3. 对缺少关键词但有视觉候选的样本，试验延迟到视觉核验再拒识，保留Unknown错误接受约束；不得直接把高相似度当接受理由。
4. 试验核验器直接查看候选可靠参考图，而不是只读相似度数值。
5. 用同视频配对与单因素消融确定收益；未超过A基线前不把更复杂的B/C作为最佳方案。去重并审查新KB下GT覆盖关系后，另备未参与开发的验证/测试集，固定方法再做正式评估。

## 数据划分审计补充

按视频文件SHA-256校验，旧6条素材的`niaochao_aerial`与final31的`鸟巢`为完全相同视频。旧报告中“验证与测试零重叠”的说法不能仅凭video_id成立，历史阈值结果应注明此限制，正式论文需重新去重划分并校准。详见outputs/accuracy_repair_v2/data_split_audit.json。未修改原GT。

另发现中关村1号结构化响应含有可读文字，但因未转义引号导致JSON解析失败，被当作“无明确文化符号”。应增加有限格式恢复/重试，并把不可恢复的解析失败独立记为运行错误；本轮冻结版本尚未改动此逻辑。
