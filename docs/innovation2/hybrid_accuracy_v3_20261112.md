# 联合召回与独立视频核验 v3

目标：提高严格符号ID准确率，保留Unknown拒识能力；服务于可复现的论文实验。所有当前素材都属于开发诊断，不能声称独立测试收益。

## 本轮方法

- 复用A组命名描述作为检索假设，复用B组结构化场景及文字复核作为观察证据。
- 两者联合做Top-5文本召回。命名假设单独记录于hypothesis_provenance和retrieval_scene_text，不传给身份核验器。
- 不再用“观察文本没命中关键词”直接拒识。受控标注先在候选中判断，每个最终输出实体必须接受独立视频核验。
- 核验器读取4张视频关键帧、候选KB定义和观察证据；不读取命名假设、检索分数、GT、文件名或候选参考图。
- 接受必须给出具体可见依据；同类、同景区及范围外具名实体仍拒绝。帧不可读或核验响应格式错误记运行失败，不能算正确拒识。
- 结构化JSON格式失败最多请求一次格式恢复，校验恢复结果没有新增观察文字和定位数字；无法恢复抛出运行错误。

本轮同时改变检索与核验，属于工程组合实验，不把差异归因于单个模块。最终应补充分模块消融和同时间重跑的A基线。

## 参考图审计

KB v2共有149条本地参考图记录，全部标记candidate_unreviewed、use_for_retrieval=false。旧多模态检索和身份视觉索引未检查这些字段，仍加载了图像。这会影响历史结果的解释；不能把旧相似度当作已经审核的可靠身份证据。

本轮只使用文本召回及原视频帧，不读取这些参考图。没有擅自将其标记为人工审核通过。审计明细：experiments/innovation2/outputs/hybrid_accuracy_v3/reference_policy_audit.json。

## 实验配置

同一批A/B均有落盘结果的20条视频；18 Known、2 Unknown。固定GT、KB、temperature=0、Top-5。与A/B配对20条，与C配对18条。部分JSON恢复可能新增文字复核调用，单独记录成本。缓存A/B证据的提取成本不是零，不能以“新增调用数”代替全链路成本。

运行：

```bash
python -m unittest discover -s tests -v
python -u scripts/innovation2/run_hybrid_accuracy.py --output-dir experiments/innovation2/results/hybrid_accuracy_v3 --workers 3
```

36项回归测试通过，包含假设与身份核验严格分离、解析恢复不能新增身份内容、缺帧不能冒充未知、未审核参考图及检索分数不进入独立核验。

上一轮v2的114项冻结输入已按原哈希打包为results/accuracy_repair_v2/frozen_inputs.zip，避免本轮代码修复影响旧结果复现。

## 结果

完整20/20已完成。最终目录：[hybrid_accuracy_v3_complete/report.md](../../experiments/innovation2/results/hybrid_accuracy_v3_complete/report.md)。

|指标|A基线|H3|
|---|---:|---:|
|严格准确率|14/20=70%|18/20=90%|
|Known准确率|12/18=66.67%|16/18=88.89%|
|Unknown拒识|2/2|2/2|

相对A新增正确4条：中关村1号、中关村展示中心、北大1、庙会；无退步。剩余京剧青衣和北大均为召回缺失。与B比为5/20→18/20；与C共同18条比为5/18→16/18。

首轮18条成功结果继承，cbd1、 中关村1号因格式错误在修复后补跑。两次代码快照、源结果哈希及继承清单均保存；135项冻结输入核验一致。语法恢复仅增加错误分支，继承样本已验证原始场景/核验JSON均合法。完整结果不能伪称单次无错误运行。

新增的字段恢复直接保留可独立解码的原JSON字段，只允许一个可选字段损坏，丢弃字段有明确审计；不补写任何观察。核验响应的非法转义仅按字面反斜杠保留，不改变判断词句。

成功预测路径37次逻辑API调用；所有已落盘尝试共52次，其中12次网络失败。没有token或金额数据，缓存A/B提取成本另计。

该结果是开发集增益，尚不能证明独立泛化或统计显著。正式论文需固定本版后做同时间A基线、分模块消融以及新数据验证。

## 正式论文边界

旧验证素材与final31有一个完全相同视频；正式校准前须按内容哈希及拍摄来源去重。Unknown只有2条，零误接受也不能证明开放集泛化。最终需要未参与本轮开发的新验证/测试素材，并审查新KB下GT的实体范围与覆盖关系。
