# 指标阅读与人工复核注意事项

本次预先规定仅接受规范名与登记别名，不用关键词或任意子串计身份分。这个规则对六维旧回复和C-only新回复的自然语言措辞存在敏感性。例如“CBD天际线”并非登记别名，会被记为未匹配，不能因此断言模型完全不认识CBD。反之，输出一个正确名称加其他具体身份，也不能只取正确名称掩盖多报。

- 自动`wrong_identity`是“没有命中主要实体登记名”的机器分类，并不都是视觉上错误命名。需结合原文进一步区分泛化描述、名称限定词未规范化、具体身份混淆和标签问题。
- 自动`reference_extra_entities`表示输出与单主体参考集合不匹配，不代表经人工确认的错误附加实体。例如红墙、石狮等可能只是一般视觉要素；另一些具体地标可能确实可见，但原GT未穷尽。
- 附加实体的真实错误数、完整多实体P/R/F1须人工完善参考集合后才能确定。本轮保留全部原文与逐条辅助提取，不把自动FP直接称作视觉事实错误。
- 主实体命中率和无附加不匹配的严格命中率同时报告。前者允许附加实体，后者更严格，二者不能混用。
- 不通过测试结果增加新别名、改文化类别或改主要实体标签。本轮仅修正方括号装饰符的规范化实现，使其符合已经冻结的标点规则；记录见evaluation_implementation_correction.json。其余冻结参数保持不变。
- Free/Text来自六维Prompt，Image/Multimodal来自C-only Prompt，且KB版本不同，差异包含提示格式与库版本影响，不作为纯检索模态的因果提升结论。Image与Multimodal的新运行条件一致，可更直接配对比较。
