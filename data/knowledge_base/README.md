## 数据内容

每个实体保留稳定ID、规范名称、别名、文化分类、地域、类型、视觉特征、空间特征、典型场景、文化内涵、关键词、关联实体、来源和审核状态等原有字段。字段定义、来源目录、图片来源、尺寸、SHA-256、目视审核说明及用户确认记录均已并入同一JSON。

图片经用户对话“可以 这些图片都通过确认”确认。43张库内图设置为human_verified并启用检索；另外4张放在supplementary_reference_images中，尚无对应实体，暂不参与检索。

当前30视频涉及的18个已入库实体均有新参考图；全库其余106个实体暂没有已确认参考图，文本知识仍保留。网页发布日期与拍摄日期分开，未注明日期不推断。天安门条目包含已确认的广场及关联城楼视角，具体范围见逐图说明。
